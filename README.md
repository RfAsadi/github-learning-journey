# My GitHub Learning Journey

## About This Repository

This repository documents my six-month journey to understand GitHub,
open-source collaboration, repository management, automation, CI/CD,
security, and project maintenance.

My goal is to move beyond simply using GitHub and develop the knowledge
and practical skills needed to contribute to and eventually maintain
software projects.

## Learning Goals

- Understand Git, GitHub, and the open-source ecosystem.
- Learn how to manage repositories, branches, commits, and pull requests.
- Understand collaboration workflows and project documentation.
- Explore GitHub Actions and CI/CD automation.
- Learn about repository security and software supply-chain protection.
- Practice contributing to open-source projects.
- Build the skills needed to maintain my own projects.
